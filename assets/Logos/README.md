# Logos

Copied verbatim from orbi-website `public/`. The mark is a ring cut open at the upper right, with a small `signal` square set into the gap. There is no separate wordmark file: the site sets the word "Orbi" in `wordmark` type beside a 28px mark.

- `logo-mark.svg` — the mark for light grounds. Ring ink `night` (#06151b), square `signal` (#ffb000). Use on `paper`, `paper-2`, `surface-page` (product).
- `logo-mark-on-dark.svg` — the same mark for night. Ring ink #edf5f0 (the `ink` of the dark theme), square `signal`. Use on `night` / the dark theme.
- `favicon.svg` — the app icon: a 64×64 `night` tile with 10px corners, the ring in #edf5f0 and the `signal` square. Browser tabs and avatars only.

The inks are fixed hex fills, not `currentColor`: pick the file by ground, never recolour. Never use the amber square alone, and never set the mark on `signal`.
